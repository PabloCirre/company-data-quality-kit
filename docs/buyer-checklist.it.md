# Checklist per acquistare dati aziendali

Di **Pablo Cirre — CompaniesData.cloud**. Prima di acquistare o rinnovare,
conserva ogni risposta del fornitore con la relativa prova. Un CSV ben formato
non è sufficiente per valutare un acquisto.

1. **Unità:** chiarisci se ogni riga rappresenta un'impresa, una filiale, una sede
   o un contatto. Richiedi la definizione dell'identificativo e un esempio con più
   sedi. Non confrontare conteggi riferiti a unità diverse.
2. **Copertura:** definisci paese, settore, forme giuridiche, stato attivo/inattivo
   ed esclusioni. Chiedi la popolazione di riferimento e la sua data. Un numero
   elevato di righe non dimostra la copertura del mercato desiderato.
3. **Campione:** chiedi come è stata selezionata la demo. Concorda, se possibile,
   una selezione casuale o stratificata e annota i segmenti assenti. Un campione
   scelto per presentare i risultati migliori non rappresenta tutto il prodotto.
4. **Provenienza:** per i campi rilevanti chiedi fonte, data di osservazione e
   trasformazioni. Distingui valori osservati da stime e dati di registro da
   informazioni di contatto provenienti da altre fonti.
5. **Uso consentito:** richiedi licenza o contratto per la finalità prevista:
   analisi, contatto commerciale, ridistribuzione o addestramento. Esamina
   conservazione, attribuzione, condivisione e responsabilità sui dati personali.
   L'accesso pubblico non equivale a una licenza di riuso o al permesso di contattare.
6. **Aggiornamento:** separa data di esportazione, raccolta, evento originario e
   ultima verifica. Concorda come ricevere cessazioni, rettifiche e aggiornamenti.
7. **Misurazione:** scegli campi obbligatori e formati prima del confronto.
   Registra separatamente denominatori, valori mancanti, errori sintattici e
   duplicati esatti. `N/A` può essere presente senza essere informazione utile.
8. **Verifica:** controlla gli identificativi nella fonte e nella giurisdizione
   appropriate. Una sintassi email corretta non dimostra una casella attiva o
   un'autorizzazione al contatto. Concorda metodo e data della verifica separata;
   questo kit non la esegue.
9. **Importazione:** verifica UTF-8, separatore, virgolette, dizionario, date e
   zeri iniziali. Esegui un'importazione ridotta e controllata: il foglio di calcolo
   può trasformare automaticamente identificativi o date.
10. **Accettazione:** fissa soglie per campo, campionamento e rimedi prima
    dell'acquisto. Concorda responsabile, tempi di correzione e trattamento
    contrattuale dei difetti. Documenta le eccezioni senza ridurre tacitamente i requisiti.

Compila e conserva:

| Voce | Evidenza disponibile |
|---|---|
| Uso previsto / unità / popolazione | |
| Selezione, dimensione e data del campione | |
| Fonti / licenza / uso consentito | |
| Campi obbligatori / regole scelte | |
| Soglie concordate / conteggi misurati | |
| Ulteriori verifiche necessarie | |
| Problema / responsabile / scadenza | |
| Decisione / revisore / data | |

Decidi se **accettare**, **richiedere correzioni** o **rinviare** rispetto ai requisiti
concordati. Allega il rapporto aggregato; condividi righe di contatto soltanto
quando necessario e autorizzato. Gli esempi sintetici non costituiscono una prova
della qualità di un fornitore. Licenza della documentazione: MIT.
