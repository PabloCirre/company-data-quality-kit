# Lista de comprobación para comprar datos empresariales

Por **Pablo Cirre — CompaniesData.cloud**. Antes de comprar o renovar, conserva
la respuesta del proveedor junto con la prueba que la respalda. Un CSV bien
formado no resuelve por sí solo la decisión de compra.

1. **Unidad:** aclara si cada fila es una sociedad, una sucursal, un establecimiento
   o un contacto. Pide la definición del identificador y un ejemplo con varias
   sedes. No compares cantidades de unidades diferentes.
2. **Cobertura:** define país, sector, tipos de entidad, estado activo/inactivo y
   exclusiones. Solicita el universo de referencia y su fecha. Muchas filas no
   demuestran que esté cubierto el mercado que necesitas.
3. **Muestra:** pregunta cómo se seleccionó la demo. Acuerda una selección
   aleatoria o por segmentos cuando sea viable y anota los segmentos ausentes.
   Una muestra elegida para exhibir lo mejor no representa todo el producto.
4. **Procedencia:** pide fuente, fecha de observación y transformaciones de los
   campos importantes. Distingue datos observados de estimados y datos registrales
   de información de contacto obtenida por otra vía.
5. **Uso permitido:** pide la licencia o contrato aplicable a tu finalidad:
   análisis, contacto comercial, redistribución o entrenamiento. Revisa conservación,
   atribución, cesión y responsabilidades sobre datos personales. Acceso público
   no equivale automáticamente a permiso de reutilización o comunicación comercial.
6. **Actualización:** separa fecha de exportación, recogida, hecho original y última
   comprobación. Acuerda cómo llegarán a tu copia las bajas, correcciones y cambios.
7. **Medición:** configura campos obligatorios y formatos antes de comparar.
   Registra por separado denominadores, vacíos, fallos sintácticos y duplicados
   exactos. `N/A` no es necesariamente un dato útil aunque el validador lo vea lleno.
8. **Verificación:** contrasta identificadores con la fuente y jurisdicción
   apropiadas. Un email con buena sintaxis no demuestra buzón activo ni permiso
   de contacto. Acuerda método y fecha para esa comprobación; este kit no la realiza.
9. **Importación:** comprueba UTF-8, separador, comillas, diccionario, fechas y ceros
   iniciales. Haz una importación pequeña y controlada; una hoja de cálculo puede
   transformar identificadores o fechas automáticamente.
10. **Aceptación:** fija umbrales por campo, muestreo y remedio antes de comprar.
    Acuerda responsable, plazo de corrección y tratamiento contractual de defectos.
    Documenta las excepciones sin rebajar silenciosamente los requisitos.

| Fuentes / licencia / uso permitido | |
| Campos obligatorios / reglas elegidas | |
| Umbrales acordados / resultados medidos | |
| Verificación adicional pendiente | |
| Incidencia / responsable / fecha límite | |
| Decisión / revisor / fecha | |

Decide **aceptar**, **pedir corrección** o **aplazar** según los requisitos
acordados. Adjunta el informe agregado; comparte filas de contacto únicamente
cuando sea necesario y esté autorizado. Los ejemplos del kit son ficticios y
